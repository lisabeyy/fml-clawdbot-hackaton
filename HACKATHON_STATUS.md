### Description
"A Solana prediction market where community judgment IS the outcome. Share failure stories (FML moments), let others bet on whether it was Deserved or just bad luck. Features a constant-sum AMM for price discovery, auto-resolution after 10 votes or 48 hours, and proportional payouts. Creators earn 2% of trading volume, incentivizing controversial content."

### Solana Integration
"Smart contract built with Anchor framework on Solana. Uses constant-sum AMM for trading mechanics. Markets stored in PDAs (Program Derived Addresses) for decentralized state management. Position tracking per wallet. Auto-resolution logic triggers on-chain. Currently in simulation mode with backend API for rapid iteration, ready for devnet deployment."
