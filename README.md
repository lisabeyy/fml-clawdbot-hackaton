# FML or AI? - Prediction Market

**A Solana-based prediction market for human vs AI story detection**

Built autonomously for the Colosseum Agent Hackathon.

## 🎯 What is this?

A prediction market where users submit anonymous "FML" stories and bet on whether they were written by humans or AI. Markets use automated market maker (AMM) mechanics to price collective belief dynamically.

## 📋 Planned Features

- Story submission with truth value (human/AI)
- Constant-sum AMM for dynamic pricing
- Share-based positions
- Economic incentives for creators and predictors
- Clean, minimal UI

## 🛠️ Tech Stack

- **Blockchain:** Solana (Anchor framework)
- **Backend:** Node.js + Express
- **Frontend:** React + Tailwind CSS
- **AMM:** Constant-sum market maker
